# cloud-computing-project

there is one .env file whichh carry aws access key and secret key.
Format for .env file is
export SECRET_KEY='Your aws Secret key'
export S3_BUCKET='Your s3 bucket name'
export S3_ACCESS_KEY='Your Aws access Key'
export S3_SECRET_KEY='Your aws Secret key'

by the help of this format you can upload your data on aws cloud .
